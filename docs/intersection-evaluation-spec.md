## 3. 需求与使用场景

### 本轮HPO现行流程（Q35–Q44）

Q44守护gate：在固定子集之前检查完全重复几何。发现则在内存/派生输入中自动去重，显式告警并写日志，记录来源重复ID、保留ID、重复组以及原始/有效数量。源GPKG不变；不做近似去重、不合并仅邻近或相交的路口。本次305/306为同一组，有效数量110。确定性代表ID与映射用于恢复和审计。

S0固定父Refine → S1抽取正样本子集 → S2从正样本面生成评价ROI → S3向外buffer 200米并集得到计算ROI → S4从父Refine筛选相关subtrack和点 → S5局部Detect → S6筛选评价ROI内最终预测路口，保留完整几何（Q41更正） → S7局部F1 → S8独立提交trial结果。

计算ROI只是从既有Refine选择输入，不重新执行Refine；200米以米制处理坐标系计算，不以经纬度数值缓冲。Q38固定嵌套子集；Q39以本级所选原始正样本面的并集为评价ROI；Q40原面米制buffer200米并集为计算ROI；Q41只筛选预测对象、不切割面，区外预测不计FP。Q42采用完整原面几何质心covers评价ROI（包含边界），合并ROI后对象只计一次；Q43只保留计算ROI内及边界的连续轨迹片段，离开重入断段，不带入区外邻点。不得宣称该固定200米邻域保证全域Detect等价。


- 编辑同一份本地 TOML；配置当前选择、命名案例、参数方案与评价规则。后续网页及命令行共用解析、校验、快照机制（Q5、Q7）。
- 案例必须提供 source_table、带时区时间范围、GeoJSON 多边形文件或 bbox 两顶点二选一；缺失时报错（Q11–Q14）。
- GeoJSON 支持 Polygon/MultiPolygon；多个区域面取并集。QGIS 仅作编辑器，不要求插件传图层。源文件集中保存，运行归档实际副本。
- 一次启动多个显式命名方案，顺序执行、各自独立记录。单方案失败继续；共同输入无效则停止批次（Q9、Q17）。
- 真值为带唯一 ID 的交叉口面 GeoJSON。无真值允许运行，显示“未评价”；可后补真值评价已有结果（Q21、Q22）。
