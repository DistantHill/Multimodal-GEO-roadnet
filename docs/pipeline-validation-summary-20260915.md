## 代码库修改

盘点本汇总创建前的工作区：22 个已跟踪文件修改（+1205/-1218 行），25 个
新增文件（9 个运行模块、14 个测试/辅助文件、2 个文档）。这是工作区状态，
不将全部未提交内容认定为本次任务独占产生；本汇总为随后新增的文档。

| 范围 | 已实现行为及主要文件 | 取舍与边界 |
| --- | --- | --- |
| 候选职责拆分 | `candidate_patches.py` 管分批，`detect_candidates.py` 管提取调度、全局编号和进度；`turn_events.py`、`cross_track.py` 保留单批内核；去除旧 method 名称混淆 | 当前数据库路径单 Python 进程，批次串行；分批不等于多进程。`stream_batch_size` 为 1000 |
| 磁盘空间工作区 | `detect_workspace.py` 暂存轨迹、线段、候选；R-tree、航向桶及覆盖索引减少配对和读取；命中后解码完整来源 | 减少驻留对象，增加 SQLite 文件和 I/O；不承担断电恢复职责 |
| 转向、候选及成员暂存 | `clip_spool.py`、`cross_member_store.py`、`detect.py` 使用可重复遍历的磁盘序列、紧凑 XY 与延迟成员视图，缓存来源统计，消融比较仅保存质心 | 避免全部候选及成员对象常驻；拓扑等其他集合仍可能增长 |
| 紧凑 DBSCAN | `dbscan_storage.py` 与 `detect.py` 使用整数数组、活动索引链、三态 bytearray；保留全局升序入栈和后进先出扩展 | 语义回归通过；仍为随候选数增长的全局算法，不是固定内存保证 |
| Detect 写入器 | `writer_workspace.py`、`db_writer.py` 通过磁盘排序、归并和分批 COPY 处理来源映射、成员归属及已解析序列 | 保留 p/i/c 顺序、来源关系及冲突检查；小规模耗时可能增加 |
| Clip 查询及暂存 | `db/queries.py` 逐个完整子轨迹流式读取，移除大聚合及逐点连接；`db/cursors.py` 仅在 DECLARE 时改变游标规划并恢复；`clip.py` 将片段暂存磁盘 | 避免首批结果长时间等待；不把规划参数扩大到所有读取器 |
| Fitting 内存 | `fitting.py` 按交叉口对暂存，采样用内存映射、分块精确中位数，释放已访问映射页 | 增加临时磁盘需求；不是改变拟合统计量 |
| 进度与生命周期 | `heartbeat.py` 提供累计详情；外层提取/查询/排序/提交心跳；`pipeline.py` 与结果 close 管理暂存关闭，KeyboardInterrupt 回滚并标记未完成 Run 失败 | 心跳线程不承担并行计算；提交成功才代表持久化完成 |
| 公共模型与几何 | `models.py` 接受磁盘 Sequence；`_geometry.py` 统一处理投影坐标访问与缺失检查 | 配套行为回归、写入器集成测试及小型性能核对 |

两个数据库 validate 的逐项解释和停用属于文档与数据库状态变更；当前
`parser.py`、`cli/init_db.py` 没有工作区 diff，没有从代码库删除数据库函数定义。
当前停用不能推导为以后执行初始化仍保持停用，现有审查记录已描述维护边界。

数值内存映射宽筛、空间源顺序等隔离实验未合入当前生产链路；临时候选捕获/
恢复驱动也未加入产品 CLI。此次停止后不继续这些实验或实施多进程改造。
