# 跨轨迹端点向量夹角修正验证

日期：2026-09-30。术语遵循 [项目术语与写作规范](../terminology.md) 。
设计依据： [列式架构 Spec 第 4.7 节及 Q113](../pipeline-columnar-architecture-spec.md) 。

## 变更与边界

跨轨迹线段对的夹角改用投影端点向量。NumPy 对每个网格的保留线段一次批量计算
`bearing = degrees(atan2(x_end-x_start, y_end-y_start)) % 360`，方向分桶、候选过滤、
精确内核复用同一方向数组；外存路径按读取的线段块计算，左块方向在多个右块间复用。
候选仍按有界 ID 对批次求交，不建立全网格两两矩阵。

DuckDB 已有配对路径在物化临时线段关系时生成 `dx`、`dy`、`bearing`，配对阶段复用。
SQL 角度筛选保留浮点边界余量，最终由 NumPy 精确内核判断。SQL 内部新增派生列显式
排除在原 23 列来源解码投影之外，原坐标、来源身份及输出 `heading` 属性保持。
稠密及压缩参考几何函数也改为端点几何语义，调用方不再传入源 `heading` 作为角度。

此次不改变单线段的起终点 heading 差直线条件、端点平均速度条件、同子轨迹排除、
格内/跨格配对身份规则。零长度和共线段继续由精确求交的行列式条件排除。

## 固定 grid00 只读复测

输入来自既有导出中的固定线段缓存
 `/data/tmp/road-network/cross_track_filter/_repro/segments.pkl` ，共 111,647 条线段。
Refine ID 为 `f76bab1e-1af1-45d0-9368-cc2a67aceb04`。
使用既有导出元数据中提交 `ddab545` 的完整 Pipeline 配置参数；分别将平均速度阈值
设为 0 和 20。读取已有 CSV 核对 86321 历史交点，没有新建或覆盖导出 CSV，也没有
修改数据库结果。

| 核查项 | 结果 |
| --- | ---: |
| 86321 原有交点记录 | 2,586 |
| 这些记录通过新几何角度判定 | 0 |
| 关闭速度筛选，整个 grid00 新交点记录 | 1,750,089 |
| 关闭速度筛选，86321 新交点记录 | 0 |
| 速度阈值 20，整个 grid00 新交点记录 | 0 |

整个 grid00 的新结果按批次用独立的向量点积/反余弦公式复核，没有复用生产的方位角
函数。全部结果在 80–100° 范围内，实际最小值为 80.00000109929582°，最大值为
99.99999873677727°；数值核对容差为 1e-10°。

角度定义变更会同时剔除旧误收配对、补回旧角度筛选遗漏的几何合格配对，因此总记录数
不要求是旧版 1,701,155 条记录的子集，也不要求保持旧版 CSV 哈希。
