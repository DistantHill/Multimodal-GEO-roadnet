# 富平局部 HPO 零分诊断（2026-10-12）

## 结论与修复

本次全部 60 次 F1=0 的直接原因是评价对象不匹配。用户在 Q52 确认，标注圆是圈定路口位置的区域，不是真实路口边界。Detect 输出圆则包含拓扑计算范围，半径为 `max(90m, candidate_radius + 70m)`。将二者要求 IoU≥0.70 会否决本来中心距离合格的预测。

所有保存结果重新核算均与原评分一致；全部配对的最大 IoU 只有 0.239405。仅按最小输出圆面积估算，110 个标注中已有 106 个不可能达到 0.70。投影差异不会改变这些配对结论。

已将这批定位标注改为中心距离≤30m的一对一匹配；完整预测面质心位于评价 ROI 内及边界才参与评价，区外结果不计 FP，对象几何不切割。评价规则及标注语义进入搜索身份。原搜索、晋升历史、60 份评分全部保留，在 `roadnet_eval` 追加 60 份修正评分，没有新增 Detect 搜索调用。

## L1 漏检归因

L1 调试运行：`6d35a5fb-8de5-4ce0-99d0-855d85b2b5bc`。5,977 个转向事件筛得5,882个候选，其中5个为噪声；形成18个候选簇，7个通过拓扑，4个中心位于评价区，最终 TP=3、FP=1、FN=17、F1=0.25。

20个真值的互斥归因如下。该顺序用于解释最终漏检，不代表前面归类对象没有后续阶段问题。

| 归因 | 数量 |
| --- | ---: |
| 正确匹配 | 3 |
| 中心30m内有候选，但没有簇中心满足30m | 13 |
| 簇中心满足30m，但拓扑检查淘汰 | 3 |
| 中心30m内没有候选 | 1 |

例如真值18附近有306个候选，所属簇共1,267点，簇中心偏离50.65m；真值193附近有50个候选，却与真值9附近的候选进入同一1,486点簇，最近簇中心距离193为322.28m。两个簇各含多个标注附近的候选。这说明数量充足不保证形成各自独立且定位正确的路口簇。

位置合格但被拓扑淘汰的是27、9、1737，分别只有0、43、1次完整进出观测，分支数0、2、2。对全部18个簇，分支不足3的有10个、观测不足6的有8个、有向转移不足3的有11个；这些失败条件可重叠，合计不能当作淘汰总数。

全部11个被淘汰簇的拓扑圆都未被计算 ROI 完整覆盖。例如簇2半径413.5m，加70m后需要483.5m的拓扑圆，其周界只有约26.3%落在计算 ROI 中。当前算法只在同一局部轨迹中配对真实的入圆、出圆事件；从圆内开始或缺少出圆的片段不能生成完整观测。固定200m外扩与随簇增长的拓扑圆存在范围不匹配，但这只是已测得的限制，不能据此断言每一次淘汰都由 ROI 裁切造成，仍需更大上下文的对照实验。没有自动放宽 ROI 或拓扑阈值。

## L2 漏检归因

L2 调试运行：`d9e5af75-860d-436e-b90e-bc71d91036f7`。18,318个候选中29个为噪声；形成32个候选簇，13个通过拓扑，7个进入评价区，最终 TP=5、FP=2、FN=45、F1=0.175439。

| 归因 | 数量 |
| --- | ---: |
| 正确匹配 | 5 |
| 中心30m内有候选，但没有簇中心满足30m | 39 |
| 簇中心满足30m，但拓扑检查淘汰 | 3 |
| 中心30m内没有候选 | 3 |

47/50个真值附近存在候选，不能把低召回主要解释成缺候选。10个簇包含多个标注附近的候选。最典型的簇2有4,599点，同时覆盖真值16、18、193、246、9附近的候选，但簇中心不在任何一个真值中心30m内。它的候选半径697.86m、拓扑半径767.86m，拓扑周界只有7.62%落在计算 ROI 中；最终82次完整观测只形成1个分支、1种有向转移，被淘汰。

L2共19个簇被拓扑淘汰：16个分支不足、16个有向转移不足、3个完整观测不足，条件可重叠。这19个簇的拓扑圆也全部未被计算 ROI 完整覆盖。中心合格但淘汰的真值为168、1737、23；无30m内候选的真值为1717、1726、1732。

因此应分开处理三个问题：零分评价口径已经修复；候选簇合并及中心偏移是剩余漏检的主要直接环节；拓扑圆与局部输入范围不匹配是可测得的另一项限制。需要对照实验决定是否调整聚类范围或拓扑上下文，不能凭当前报告直接调整200m边界、DBSCAN或拓扑门槛，也不能保证只搜索转向阈值即可解决。
